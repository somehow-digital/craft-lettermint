---
title: Dashboard widget
description: A compact overview right on your dashboard.
---

Add the **Lettermint** widget to your dashboard. It's a compact version of the [utility](/features/utility/). This is a Pro feature.

It shows:

- team and plan,
- usage this billing period,
- sent, delivered, hard bounces and spam complaints over 28 days, with a daily chart.

It shares its data with the utility. Only users with the **Utilities** → **Lettermint** permission can add or see it.
