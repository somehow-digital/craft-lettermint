---
title: Editions
description: What the Lite and Pro editions include.
---

The plugin comes in two editions. Lite sends your emails through Lettermint. Pro adds per-site settings, insights in the Control Panel, webhooks and health checks.

| Feature                                                 | Lite | Pro |
| ------------------------------------------------------- | :--: | :-: |
| Mail transport                                          | Yes  | Yes |
| [Route](/features/route/)                               | Yes  | Yes |
| [Tags](/features/tags/)                                 | Yes  | Yes |
| [Sites](/features/sites/) with their own route and tags |      | Yes |
| [Craft metadata](/features/metadata/) on every email    |      | Yes |
| [Utility](/features/utility/)                           |      | Yes |
| [Dashboard](/features/dashboard/)                       |      | Yes |
| [Webhooks](/features/webhooks/) as Craft events         |      | Yes |
| [Health endpoint](/features/health-endpoint/)           |      | Yes |
| [Health command](/features/health-command/)             |      | Yes |

The Pro [settings](/guide/settings/#pro-settings) appear below the lite settings in the Control Panel.
