## Installation

Install the plugin from the [Plugin Store](https://plugins.craftcms.com/lettermint) in the Control Panel, or with [Composer](https://packagist.org/packages/somehow-digital/craft-lettermint):

```sh
composer require somehow-digital/craft-lettermint
php craft plugin/install lettermint
```
